주요 기능.

노래방 한 대가 차 안에 들어왔습니다.

🔎

바로 검색해서 부르기

제목·가수로 검색하면 반주 영상이 바로 재생돼요. 타이핑하는 대로 실시간으로 결과가 뜹니다.

🎙️

음성으로 검색 무료 키 필요

버튼을 누르고 곡·가수를 말하면 찾아줘요. Google의 무료 Gemini 키를 넣으면 켜지고, 조회 후 첫 곡을 자동 재생합니다.

💯

마이크 채점

부른 목소리를 분석해 음정·안정성·박자·표현을 점수로. 노래방식 점수 연출까지.

📱

폰으로 예약 (리모컨)

승객들이 각자 휴대폰으로 QR을 찍어 검색·예약. 부르는 중에도 대기열이 쌓이고 순서대로 이어집니다.

🔁

다시 듣기

내가 부른 녹음을, 같은 타이밍의 영상(가사)과 함께 다시 감상해요.

💾

녹음 저장 · 공유

SD카드·내부 저장을 선택하고 용량은 자동 관리. QR로 내 노래를 휴대폰으로 받아갈 수 있어요.

음성 검색 켜기.

타이핑 없이 말로 곡을 찾는 기능은 선택이에요. Google의 무료 Gemini 키만 넣으면 켜집니다.

aistudio.google.com 접속 → 구글 로그인 → 「Get API key」로 무료 키 발급.
앱 설정 → 음성 검색 칸에 그 키를 붙여넣고 저장.
검색창에 🎙 음성 버튼이 생겨요. 누르고 곡·가수를 말하면 검색됩니다.
무료 한도가 넉넉한 flash-lite(1000회/일) · 정확한 flash(250회/일) 중 선택 가능. 키는 본인 것을 쓰며 앱엔 저장만 됩니다.

설치 방법.

스토어가 아닌 APK 직접 설치(사이드로드)입니다.

APK 내려받기 — 위 버튼으로 최신 APK를 받습니다.
"출처를 알 수 없는 앱" 허용 — 설정에서 설치 권한을 켜주세요.
설치 후 실행 — 마이크 권한을 허용하면 바로 부를 수 있어요.
업데이트 — 새 버전이 나오면 앱이 알아서 확인·설치합니다(OTA).
